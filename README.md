# Ultraverse

A dynamic, highly interactive NFT gallery application designed to simulate a premium web3 marketplace ecosystem. The platform leverages fluid, high-performance transitions and micro-interactions to create an engaging user experience. Key features include an intuitive creator-driven navigation system for exploring digital artist portfolios and a comprehensive NFT catalog that users can dynamically sort by price.

## Getting Started

### Prerequisites

* **Node.js:** `v16.20.2` (or any Node `v16` / `v18` LTS)
  * *If you use [nvm](https://github.com) (or [nvm-windows](https://github.com)), run:*
    ```bash
    nvm install 16
    nvm use 16
    ```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd giovanni-internship
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm start
   ```
   *(Note: If you are running Node `v18+` and encounter an `ERR_OSSL_EVP_UNSUPPORTED` error, start the app with `NODE_OPTIONS=--openssl-legacy-provider npm start`.)*

   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application locally, or visit the live deployment at [giovanni-internship.vercel.app](https://vercel.app).
